🎨 Theme System Update Tool

📋 Update Instructions

Please follow these steps to add theme switching functionality to all pages:

1. Add theme CSS in the <head> tag:

<link rel="stylesheet" href="css/theme.css">

2. Add theme script before </body> tag:

<!-- Theme switching script --> <script src="js/theme.js"></script>

3. Keyboard shortcuts:

Users can use Ctrl/Cmd + Shift + T to quickly switch themes
