🎨 Theme Operations

✅ Recommended Actions

1. Click the "Force Light Theme" button

2. If the problem persists, click "Clear Theme Cache"

3. Refresh the page or visit other pages to verify the effect

📋 Manual Operation Steps

  1. Press F12 to open developer tools
  2. Switch to Application or Storage tab
  3. Find Local Storage on the left
  4. Delete the theme item
  5. Refresh the page
